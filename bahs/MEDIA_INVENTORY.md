## Brand and media capture checklist

For each asset visible on the source pages, record:

| Field | Record |
| --- | --- |
| Asset ID | A stable identifier, such as `home-hero-01` |
| Page and placement | Source page URL and location in the layout |
| Asset URL | Exact public URL |
| Type | Logo, photograph, illustration, icon, document, video, or other |
| Filename and format | Original filename plus JPG, PNG, SVG, PDF, etc. |
| Dimensions or page count | Pixel dimensions for media; page count for documents |
| Description / visible caption | Concise factual description and any existing caption |
| Alt text | Existing alternative text, if present |
| Proposed use | Retain, crop, restore, replace, or omit in the private concept |
| Brand relevance | Logo, historic identity, event promotion, local-history illustration, or none |
| Rights / attribution note | Any stated owner, photographer, credit, or restriction |

## Initial design implications

- Verify whether the site uses a logo, wordmark, or only the society name in
  text before defining a replacement identity.
- Prioritize archival photographs, historic buildings, and Victorian Day
  imagery if they are available and visually usable.
- Preserve factual captions and source attribution alongside historic images in
  the private proposal.
- Keep original assets separate from newly created design assets so the society
  can clearly review what is being retained or updated.
